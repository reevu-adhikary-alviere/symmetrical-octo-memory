# Card Pull

Pull funds from a saved card payment method into a wallet. Use card pull when a consumer wants to top up their balance from a debit or credit card on file — the charge runs against the card and the wallet is credited with the amount.

Save the card as a [Payment Method](/guides/resources/payment-methods) before pulling — that's where the card details are tokenized.

## API reference

Card pull endpoints live in the [V2 API Reference](/api-v2) under **Money Movement**.
