# Global Money Transfers

Send cross-border payments to beneficiaries around the world. Global Money Transfers handles currency conversion, FX quoting, and routing funds to a recipient's bank account, e-wallet, card, or cash pickup location.

You'll work with [Beneficiaries](/guides/resources/beneficiaries) to set up recipients and their payout methods, then use the transfer endpoints to send funds. Quotes give you the FX rate and fee breakdown before you commit to a transfer.

## API reference

Global Money Transfer endpoints live in the [V2 API Reference](/api-v2) under **Money Movement**.
