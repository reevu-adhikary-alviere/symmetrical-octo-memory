Simple, powerful API

Integrate financial services with clean, RESTful endpoints. Create accounts, issue cards, and move money with just a few lines of code.

RESTful JSON API with predictable resource URLs
Idempotent requests for safe retries
Webhooks for real-time event notifications
Comprehensive SDKs for JavaScript, iOS, and Android 
# Create a new wallet for a user
curl -X POST https://api.alviere.com/v1/wallets \
  -H "Authorization: Bearer {access_token}" \
  -H "Content-Type: application/json" \
  -d '{
    "account_id": "acc_1234567890",
    "currency": "USD",
    "nickname": "Primary Wallet"
  }'
